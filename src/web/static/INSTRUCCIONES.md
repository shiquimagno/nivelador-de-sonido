En esta carpeta `static` es donde **Flask** buscará todos los archivos que no cambian (archivos estáticos). 
No pongas código Python aquí. Solo debes colocar:
- Hojas de estilo CSS.
- Scripts de JavaScript puro para interactividad en el navegador.
- Imágenes, logos o iconos de tu interfaz.
